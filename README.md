# python-regex-text-editor

This Python project is a text editing software that uses Command Line Interface, regular expressions, associative arrays, and control flow, **to**:

- 📝 **Alter texts** (Add, Delete, Replace Characters)
- 🔐 **Use cryptographic algorithms** (Uses the Numeric and Caesar Cipher)
- 🌐 **Collect Information** through a **software system** and present the frequency the information was found in the text

## How to Use The Project?

To use this project, find a **Python Environment** (Google Colab, Replit, VSCode, etc.), open this script's file, and click any 
**Run/Play button (▶)** found on the environment. 

Then, follow the basic instructions displayed in the project itself when it runs.
