# Python Text Editor - Command Line Text Editing & Analysis 

This project built on Python, can:

- 📝  **Alter texts** (Add, Delete, Replace Characters)
  
- 🔐  **Encrypt Text** (Uses the Numeric and Caesar Cipher)
  
- 🔎  Use **Searching Algorithms** to scan vast texts
  
- ⚠️  **detect AI-generated** text
  
- 📈  **visualize data** with Matplotlib

- 📊  generate **random** text
  
- 📂  **Handle and create** files

- 🔀  **Clean control flow** with switch statements instead of large-scale boolean statements

## How to Use The Project?

To use this project, find a **Python Environment** (Google Colab, Replit, Onecomplier, VSCode, etc.), open this script's file, and click any **Run/Play button (▶)** found on the environment.  

Then, follow the basic instructions displayed in the project itself when it runs.

**NOTE**: 
For file handling & saving, you should use an IDE, specifically.
